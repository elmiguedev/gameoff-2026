## ES

**Título:** Shift  
**Autor:** elmiguedev  
**Descripción corta:** Catorce salas, una tecla y un operador que ya perdió la paciencia.  
**Descripción:** Un recorrido por salas mínimas que empieza con una sola tecla y termina discutiendo con un operador que preferiría que dejaras de preguntar. Todo funciona con Shift. No es una pista; ya bastante hace el juego explicándotelo.

**Declaración de uso de IA (opcional):** Se utilizó OpenCode para guiar el desarrollo del juego y probar algunos escenarios y textos, y ChatGPT para generar algunas de las imágenes.
